# ADR-001 — Repository-owned lightweight engineering organization

Date: YYYY-MM-DD. Status: accepted.

## Decision
Use one JSON ledger, versioned work-unit contracts, bounded execution, and
Git + evidence as institutional memory. Keep implementation and acceptance
ownership separate. No generalized agent platform or duplicate scheduler.

## Consequences
Small manual supervisor updates, auditable by Git. Limitations of admission,
attribution and isolation stay visible as follow-up work, not hidden assurances.
